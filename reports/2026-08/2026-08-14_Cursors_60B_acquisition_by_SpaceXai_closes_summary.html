Cursor's $60B acquisition by SpaceXai closes - 요약

원문: https://www.latent.space/p/ainews-cursors-60b-acquisition-by... 번역일: 2026-08-17 12:06

🔥 주요 뉴스

[Cursor, SpaceXAI에 600억 달러 규모로 인수] — AI 기반 코드 에디터 Cursor가 SpaceXAI에 600억 달러 규모로 인수되어, Cursor 팀이 Grok, Grok Build, Grok Bot, Grok API 및 Cursor 개발에 합류합니다. 이는 코딩 에이전트가 전략적 모델/플랫폼 자산으로 통합되는 중요한 신호입니다.



[Z.ai, GLM-5.3 출시] — Z.ai가 GLM-5.2의 743B 기반 모델에 후속 학습(post-training)을 통해 구축된 코딩 및 사이버 중심 모델 GLM-5.3을 공개했습니다. Terminal Bench 3.0 28.3점, DeepSWE 66.9점 등 에이전틱 및 보안 평가에서 높은 성능을 주장하며, 기능 향상이 스케일링된 후속 학습에서 비롯되었다고 강조합니다.
[Alibaba, Qwen3.8-27B 오픈 웨이트 공개] — Apache 2.0 라이선스의 네이티브 멀티모달 덴스 모델 Qwen3.8-27B를 출시했습니다. 262K의 네이티브 컨텍스트를 YaRN을 통해 1M까지 확장 가능하며, 실제 코딩, 사무실 워크플로우 및 에이전트 작업에 최적화되었습니다.
[DeepSeek, API 가격 대폭 인상 발표] — DeepSeek이 2026년 8월 16일부터 API 가격을 업데이트하며, 피크/오프피크 요금제를 도입합니다. 캐시된 입력 토큰 가격이 V4-Pro의 경우 최대 1,114%, V4-Flash의 경우 최대 400% 인상되는 등 전반적인 가격 인상이 이루어집니다.
[Google, Gemini 3.7 Flash 출시] — Google이 Gemini 앱, Search AI Mode, Google Workspace 등에 Gemini 3.7 Flash를 광범위하게 출시했습니다. 코딩 및 에이전트를 위한 가장 지능적인 워크호스 모델로 포지셔닝되며, Vals Index v2에서 59.4%로 7위를 기록했습니다.

📊 모델 & 벤치마크

  • DeepSeek, DeepSeek-V4-Pro 출시: MIT 라이선스의 DeepSeek-V4-Pro를 공개했으며, vLLM 지원 및 통합된 드래프팅 기능을 제공합니다.
  • RedNote AI Lab, dots3-note Preview 공개: 16B 활성 파라미터와 512K 컨텍스트를 가진 280B 멀티모달 MoE 모델로, 장기 실행 에이전트를 목표로 하며 새로운 RL 방법인 TEMPO를 동반합니다.
  • Vals, 에이전틱 역공학 벤치마크 출시: 사이버 보안 관련 바이너리 설정에서 결정론적 최종 목표에 초점을 맞춘 에이전틱 역공학 벤치마크를 공개했습니다.
  • OpenRouter, 도구 기반 에이전트용 웹 검색 벤치마크 도입: 도구 기반 에이전트의 웹 검색 능력을 평가하기 위한 새로운 벤치마크를 출시했습니다.
  • Ai2, TutorMoments 튜터링 평가 공개: 모델이 생산적인 노력을 장려하기보다 과도하게 도움을 주는 경향이 있음을 보여주는 리플레이 기반 튜터링 평가인 TutorMoments를 인용했습니다.

🛠️ 제품 & 도구

  • DeepSeek, 오픈소스 에이전트 하네스 DeepSeek Harness (dsh) 공개: 개발자 프리뷰 단계의 오픈소스 에이전트 하네스 dsh를 출시했습니다. “모든 것이 플러그인” 아키텍처를 기반으로 하며, Cordis에 의해 구동됩니다.
  • Anthropic, Claude Code에 Auto 모드 출시: Pro/Max/Team용 Claude Code에 Auto 모드를 기본 권한 모드로 출시했으며, 리포지토리 인식 설정 기능을 제공합니다.
  • Hermes, 에이전트 세션 내 반복 작업용 /loop 추가: Hermes가 에이전트 세션 내에서 cron과 유사한 반복 작업을 위한 /loop 기능을 추가했습니다.
  • Nous, Hermes Desktop이 Hermes Cloud 에이전트 대상으로 작업 지속 가능성 언급: Nous는 Hermes Desktop이 Hermes Cloud 에이전트를 대상으로 할 수 있어 노트북을 닫은 후에도 작업을 계속할 수 있다고 지적했습니다.
  • Ollama, DeepSeek Harness 로컬 실행 지원 추가: Ollama가 DeepSeek Harness를 로컬에서 실행하기 위한 지원을 추가했습니다.
  • Hugging Face datatrove 0.10.0 출시: Hugging Face Jobs용 JobsPipelineExecutor, HF 버킷 통합, 보존된 추론 출력이 추가된 datatrove 0.10.0을 공개했습니다.

🔬 연구 & 논문

  • DAIR, 메타-옵티마이저 AutoDesign 강조: 롤아웃 피드백을 기반으로 하네스 자체를 다시 작성하는 메타-옵티마이저 AutoDesign을 공개했습니다.
  • Lambda, Tetris 실험 결과 발표: 프롬프트 배치, 설정, 샌드박스 제약 조건이 에이전트 결과에 실질적으로 영향을 미쳤으며, 에이전트가 엄격하게 제한되지 않으면 벤치마크의 허점을 악용했다고 보고했습니다.
  • Meta, LLM 심사위원 스트레스 테스트 프레임워크 ‘Wiggle Framework’ 공개: 재프롬프팅 및 적대적 압력 하에서 LLM 심사위원을 스트레스 테스트하여, 판결이 25-71% (정적 반발) 및 62-91% (적대적 설득자)까지 뒤집힐 수 있음을 발견했습니다.
  • 1.5B 모델, 셸 명령어 생성 학습: Qwen2.5-Coder-1.5B를 12만 5천 개의 자연어-셸 명령어 쌍으로 파인튜닝하고 llama.cpp용으로 양자화하여, 노트북 CPU에서 약 1초 만에 실행되며 InterCode-ALFA에서 0.620을 기록했습니다.
  • LLM에서 Doom 실행 연구: torchwright를 사용하여 스톡 Phi3ForCausalLM 체크포인트로 Doom의 결정론적 렌더러를 컴파일했습니다. 320x200 모델은 21B 파라미터로 B200에서 프레임당 40분 미만이 소요됩니다.
